# Software

This software will enable live shows to manage the multi media presentation in an distributed maner over the internet. Using an server client architecture, the server will be responsible to send audio and video to the necessary devices as audio interfaces, tv and projectors. system operators can be audio technicians, musicians, show managers and others. 

# Audio and Video technician

They are responsible for managing the audio an video content available in the server

# Worship Leader

The worship leader can reorganize the order of the audio visual items and change the item as they are responsible for the execution of the show.

# Musician
Musicians can follow worship lyrics and, whem available, sheet music and chords.
